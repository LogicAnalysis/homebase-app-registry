File Browser Documentation

Web-based file manager to create your own personal cloud.

Your credentials were set when you first launched the app. If you forget those original admin credentials, you will have to uninstall and reinstall this app to enter new ones!

Accessing the Interface

File Browser provides a complete graphical interface right from your web browser.

Managing Users and Directories

As the administrator, you can grant access to friends or family by creating isolated user accounts. Each user can have their own scope (the root folder they are allowed to see).

  • Click on Settings in the left sidebar, then navigate to the User Management tab.
  • Click New to create a user.
  • Set their username, password, and explicitly define their Directory Scope (e.g., /mnt/storage/alice_files). If left blank, they will have access to the entire default file tree.
  • You can also toggle specific permissions for each user, such as allowing or denying them the ability to download, upload, delete, or rename files.

Sharing Files

File Browser makes it easy to share files or folders without requiring the recipient to have an account.

  • Navigate to the file or folder you want to share.
  • Click the Share icon (usually represented by a linking symbol) in the action bar at the top right.
  • Choose how long the link should be valid, or leave it blank for a permanent link.
  • Copy the generated URL and send it to your recipient.
Pro-Tip: Global Settings & Branding

You can customize the look and feel of your File Browser instance! Under Settings -> Global Settings, you can change the name of the application, disable user registration, and even upload a custom logo to replace the default branding. This is great for setting up a personalized family cloud.
