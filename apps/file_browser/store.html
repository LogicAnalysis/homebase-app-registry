About this App

File Browser provides a clean, fast file managing interface within a specified directory on your server. It is a "create-your-own-cloud" piece of software that lets you upload, delete, preview, rename, and edit your files from anywhere, without relying on third-party cloud providers.

Whether you need a simple way to access your Homebase storage remotely, share files with friends, or edit configuration files via the web, File Browser handles it effortlessly.

Key Features:

  • Complete File Management: Seamlessly upload folders, download archives, and organize your files via a responsive web interface.
  • Multi-User Support: Create isolated accounts for family or colleagues, ensuring each user can only access their specific directory.
  • Built-in Editor: Edit text, code, and markdown files directly within your browser.
  • Shareable Links: Generate secure, expiring links to share specific files or folders with people outside your network.
  • Custom Commands: Execute predefined shell commands or scripts on your server directly from the File Browser UI.
