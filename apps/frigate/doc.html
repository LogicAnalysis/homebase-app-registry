Frigate Documentation

Complete and local NVR designed for AI object detection.

Accessing the Dashboard

To view your cameras, access events, and manage settings, navigate to the Frigate Web UI. This can be reached by typing your Homebase IP address into your browser followed by the port 5000 (e.g., http://your-server-ip:5000). You can check the Homebase system settings to verify your exact IP.

Adding Cameras

Frigate uses a configuration file to understand your network topology and camera feeds. You can edit this configuration directly from the Config tab in the web interface.

  • Retrieve the RTSP stream URL for your IP camera (refer to your camera manufacturer's documentation).
  • In the Frigate configuration, define the camera name and add the stream URL under the inputs section.
  • Set up the desired roles for the stream, such as detect (for AI analysis) or record (for saving the footage).
Camera Stream Resolutions

For optimal performance, it is highly recommended to use your camera's low-resolution "sub-stream" (e.g., 720p or lower) for the detect role. Using high-resolution 4K streams for AI detection will cause severe Homebase CPU spikes and result in delayed notifications.

Hardware Acceleration (Detectors)

By default, Frigate runs its machine learning models on the CPU. While functional for a single camera, this is highly inefficient for multiple streams.

If your Homebase supports it, passing through a Google Coral Edge TPU or utilizing a compatible GPU will drastically speed up inference times and lower system load. You can configure your designated detectors within the configuration file to offload this processing.

Pro-Tip: Monitor Inference Speed

Go to the System page in the Frigate UI. Look at your Inference Speed. A well-configured hardware accelerator should return inference speeds below 15ms. If it's above 100ms, you are likely relying on CPU processing.

Zones & Masks

To reduce false positives and control exactly when Frigate saves an event, you can draw Zones and Masks directly in the Frigate Web UI.

  • Masks: Tell the AI to completely ignore specific areas of the camera view (e.g., a tree that moves in the wind or a timestamp burned into the video feed).
  • Zones: Define areas of interest (e.g., "Driveway" or "Front Porch"). You can configure Frigate to only alert you when a person enters the specific "Front Porch" zone, rather than just walking past on the street.
