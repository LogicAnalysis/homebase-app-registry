Immich Documentation

Self-hosted photo and video backup solution.

1. Initial Setup

Welcome to Immich! After your application finishes installing and spinning up, there are a few initial steps required to get your backup system running.

Accessing the Web UI

Navigate to your Immich instance in your web browser. Upon your very first visit, you will be prompted to create an administrator account. This account will have full access to manage users, storage, and server settings.

Important

The first user created is automatically the administrator. Ensure you use a strong password, as this account controls your entire library instance.

2. Connecting Your Mobile Device

Immich's primary feature is seamless mobile backup, similar to Google Photos or Apple iCloud.

  • Download the Immich app from the Google Play Store, Apple App Store, or F-Droid.
  • Open the app and enter your Server Endpoint URL. This should include the protocol and port (e.g., http://your-server-ip:2283/api).
  • Log in using the credentials you created in the Web UI.
  • Navigate to the Backup tab and select the local albums you wish to back up to your server.

3. Understanding Machine Learning

Immich utilizes local machine learning to categorize your photos. Everything is processed directly on your hardware; no data is sent to external APIs.

  • Facial Recognition: Automatically groups photos by the people in them.
  • Object Detection: Allows you to search your library using natural language (e.g., "dog at the beach" or "wedding cake").
  • CLIP/Search: Powers the semantic search engine.
Pro-Tip: Background Processing

When you upload a large batch of photos for the first time, your server's CPU usage will spike as it generates thumbnails and runs machine learning models. This is normal. You can monitor the progress in the Administration -> Jobs dashboard.

4. User Management

As the administrator, you can invite family members or friends to use your server. Each user has their own private library and timeline. Users cannot see each other's photos unless they explicitly add them to a Shared Album or utilize the Partner Sharing feature.
