Jellyfin Documentation

The Free Software Media System.

1. Initial Setup Wizard

When you first access your Jellyfin server, you will be greeted by the setup wizard. This process will guide you through creating your administrator account and setting your preferred metadata language.

2. Adding Media Libraries

Jellyfin needs to know where your media files are stored to serve them to your devices.

  • Go to Administration -> Dashboard -> Libraries.
  • Click the Add Media Library button.
  • Select the Content Type (e.g., Movies, Shows, Music). This is crucial as it determines which metadata scrapers Jellyfin uses.
  • Link the folder on your system where those specific files are stored.
Folder Structure Matters

For accurate metadata fetching (posters, cast, descriptions), ensure your files are named cleanly. For TV shows, a structure like Show Name (Year) / Season 01 / Show Name S01E01.mkv is highly recommended.

3. Playing Your Media

You can play media directly in your web browser, but Jellyfin shines when used with dedicated client applications.

Clients are available for almost every platform, including Android, iOS, Android TV, Fire TV, Roku, Windows, and macOS. Simply download the app on your respective device, enter your server's IP address and port (default is 8096), and log in.

4. Hardware Transcoding (Advanced)

If a playback device does not support the format of your media file, Jellyfin will convert it on the fly (transcoding). This is very CPU-intensive.

If your server has an Intel CPU with QuickSync, an NVIDIA GPU, or an AMD APU, you can enable Hardware Acceleration.

  • Navigate to Dashboard -> Playback -> Transcoding.
  • Select your hardware acceleration type from the dropdown menu to significantly reduce CPU load during playback.
Pro-Tip: User Restrictions

If you share your server with children, you can restrict their accounts in the User settings to only show media with specific parental ratings (e.g., PG, TV-Y7) or restrict playback during certain hours of the day.
